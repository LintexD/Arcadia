# Arcadia

A heavily work in progress Voxel Engine
Project started 24.10.2026 to test out Antigravity IDE
(somewhat) working features:
- ReSTIR GI/DI + SHARC lighting pipeline (still noisy, need to test on my 3080)
- Detached voxels are converted to physics objects with accurate collisions, after some time they are added back to the world
- read ARCHITECTURE.md or try `cargo run` and see for yourself
